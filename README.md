## Git and GitHub
Git tracks changes in files. GitHub is a website where you can save and share projects.
## Basic Git Commands
- `git add` prepares changes.
- `git commit` saves changes.
- `git push` uploads changes.
- `git pull` gets updates.

## Branches and Commits
A branch lets you work on changes separately. A commit saves your changes.

## Pull Requests
A pull request lets you review changes before merging them into the main branch.

## Merge Conflicts
A merge conflict happens when two changes affect the same part of a file. You fix it by choosing which changes to keep.
